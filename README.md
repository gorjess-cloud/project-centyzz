# Centyzz Hair & Beauty Salon Management System

A web-based Salon Management System for **Centyzz Hair & Beauty Salon**.

The system is designed to manage salon operations such as clients, appointments, services, staff, inventory, point-of-sale transactions, reports, user accounts, and system administration.
